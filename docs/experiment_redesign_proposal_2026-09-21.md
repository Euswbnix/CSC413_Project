# 实验重设计建议：采样稀疏化下的 CfC 与 LSTM 比较

日期：2026-09-21。状态：讨论稿；尚未实施或启动训练。

## 建议与研究问题

保留 CfC 与 LSTM 的比较主题，将主实验改为手机惯性传感器序列分类；驾驶转角预测保留为探索性扩展。先用三天 pilot 检查新任务的可行性，再锁定完整实验。最终结论只针对所用 CfC 实现和评测协议，不泛化为所有“液态网络”。

建议题目：**采样稀疏化与时间间隔信息对序列分类的影响：CfC、LSTM 和 Transformer 的受控比较。**

需要回答的问题：

1. 在规则、完整观测下，CfC 与有竞争力的 LSTM 表现如何？
2. 在相同观测点数下，近均匀与随机采样分别如何影响模型？CfC 的相对表现是否随采样安排变化？
3. 若存在差异，真实时间间隔是否有帮助？它对 CfC 与 LSTM 的帮助是否相同？

现有驾驶实验同时涉及视觉表征、标签分布、回归损失和循环单元，且已出现近常数预测。这使得“时序模型谁更好”难以单独解释。先在较简单的输入上建立有效模型，可以减少这些干扰；新数据集本身并不保证 CfC 会获胜。

## 数据与三天 pilot

首选 [UCI HAR](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones)。官方数据含 30 位参与者的六类活动，50 Hz 采样，128 点窗口；使用提供的九路逐时刻惯性信号，**不把 561 维人工汇总特征当作序列输入**。许可为 CC BY 4.0，报告中保留署名与来源。

输入是变长的 `(T, 9)` 信号及相应时间信息；输出是步行、上楼、下楼、坐、站、躺之一，属于 sequence-to-one 分类。原始完整窗口中 `T=128`，删点后长度变化。

- 第一天：按参与者划分数据、检查类别与数值分布、可视化信号、验证小批量能被过拟合。
- 第二天：运行统计特征 MLP、LSTM＋Δt、CfC；先保证各模型在干净验证集上能合理预测。
- 第三天：在验证集上试少量固定采样条件，检查逐类表现、种子波动和时间信息是否有区分力。

MLP 输入是保留点各通道的 mean/std，作为不利用顺序的基线。另报动态三类与静态三类表现。若它已接近全部序列模型，说明本任务对精细时间建模的区分力有限：据此收窄研究问题或在开发阶段更换任务，不能不断调整缺失率直到 CfC 胜出。是否继续的依据是任务可学、比较可解释，不是 CfC 在 pilot 中是否领先。

## 划分与预处理

- 沿用官方按参与者隔离的测试集；从官方训练参与者中再固定一组验证参与者。具体 ID 在模型选择前写入配置并保存。
- 窗口有重叠，禁止随机把同一参与者的窗口分到训练与验证。归一化只使用训练数据统计量。
- 测试集只在协议与超参数锁定后统一评测，不用于选择数据集、缺失率、网络宽度或早停。
- 同一窗口各通道一起保留或删除；标签和原始时间跨度不变。正确处理变长 padding，读出最后一个有效状态。

重要范围限制：官方发布的窗口信号已经经过滤波。此处模拟的是**对预处理信号的观测稀疏化**，不是原始传感器采集前的真实缺失。被删除点的信息可能已通过预处理影响保留值，不能据此声称解决了真实在线缺测。若以后研究原始采集缺失，需要原始连续数据与相应的因果预处理流程。

## 模型与公平性

| 模型 | 用途 |
|---|---|
| 统计特征 MLP | 判断不利用顺序能做到什么程度 |
| LSTM＋真实 Δt | 主比较对象，获得与 CfC 相同的时间信息 |
| CfC＋真实 Δt | 待检验的连续时间结构 |
| 小型 Transformer＋真实时间编码 | 补充参照，并对应课程列出的 Advanced Concept 方向 |

先完成前三个，主流程可靠后再加入 Transformer。序列模型使用简单、共同的逐点特征投影和分类头，不引入视觉 CNN。优先使用已核验的稠密 CfC；本轮不同时增加稀疏接线、混合记忆等结构因素。

主比较尽量匹配可训练参数量，报告投影、循环/注意力模块及分类头的实际计数和残余差异。参数匹配不等于计算量匹配，另外记录训练时间、推理时间与内存。

各模型可以选择不同学习率，但享有相同验证搜索预算、训练步数上限及数据增强条件。不能只精调 CfC 后拿默认 LSTM 比较。Transformer 使用实际时间编码，不只使用删点后重新编号的位置；所有模型都只读取同一窗口内的信息。

消融只增加两项：不输入 Δt 的 LSTM，以及将 Δt 固定为 1 的 CfC。两者分别重新训练，使用对应主模型的其余配置，以隔离时间输入的作用；测试时单独把已训练模型的 Δt 改错只能作为敏感性分析。

## 核心实验矩阵

缺失率预先固定为 `0%、25%、50%、75%`，分别保留 `128、96、64、32` 点。固定首尾端点，比较：

1. **近均匀下采样**：对原始索引区间等分并取最近整数，明确记录生成算法。
2. **随机删点**：从内部索引均匀抽取相同数量的点，再恢复时间顺序。

由于整数索引与固定端点的限制，不能把所有近均匀条件称为严格等间隔。两个条件控制观测数量与总时间范围，用于比较采样安排造成的影响；它们保留的具体信号值不同，不能宣称只改变了时间间隔而完整保留了信息内容。

时间戳保留原始索引对应的物理时间。Δt 是相邻保留点的实际间隔，并统一除以原始采样周期；不能删点后全部设成 1，也不能按每个窗口的平均间隔重新归一化。首点约定与 padding 规则在所有实现中固定并记录。

训练分成两套独立问题：

| 训练条件 | 评测条件 | 回答的问题 |
|---|---|---|
| 完整观测训练 | 完整＋各稀疏条件 | 未经过适应时的鲁棒性 |
| 混合采样训练：缺失率 0/25/50%，含近均匀与随机条件 | 完整＋各稀疏条件 | 得到同等训练机会后的表现 |

75% 缺失是预先留出的严重稀疏条件，作为次要的分布外评测。暂不同时添加噪声、缩放、遮挡、跨设备等额外因素。

各模型共享评测删点掩码。训练随机数、模型初始化与评测掩码使用独立记录的种子；缺失机制不依赖活动标签。可对固定的少数掩码重复评测，但不能把它们视为新增独立参与者。

## 指标、预算与结论

主指标建议提前定义为：**混合采样训练下，随机缺失 25% 与 50% 的 macro-F1 平均值**；主对比是 CfC 减 LSTM＋Δt。同时必须展示干净条件、同点数近均匀条件及完整曲线，才能判断差异是否与不规则采样相关。

补充 accuracy、逐类混淆矩阵、逐参与者结果和推理成本。报告绝对性能，不能仅用“比自己干净结果下降少”说明更强。

建议初始调参预算：三个主要序列模型各六个配置、两个开发种子，每套训练条件分别选择配置；模型间预算相同。最终选定配置各运行五个新种子。消融继承配置，避免将其扩大成另一轮搜索。先测一次小运行的实际耗时，再估算总成本，不沿用旧驾驶实验的 GPU 小时预测。

五个种子用于呈现优化波动；参与者之间的差异另报。置信区间以参与者为重采样单位，不能把重叠窗口或同一窗口的多个掩码当作独立样本。明确区间对应固定训练划分，不能声称覆盖全部人群、设备和采样机制。

以下结果都能构成诚实的报告：

- CfC 在完整观测下持平，在随机稀疏条件下有稳定优势，且时间消融支持解释。
- 提供 Δt 后，LSTM 追平 CfC，说明时间信息本身比所比较的结构差异更关键。
- LSTM 持平或更好，说明在该任务、实现及预算下，尚无充分依据选择 CfC。

若所有模型都接近多数类预测，应先修复任务或训练流程，这不是有解释力的“架构平手”。

## 现有工作与两个月安排

保留已有 CfC 实现、核验代码、日志/评测框架和驾驶诊断。旧驾驶结果可以解释为何重新控制研究变量。

驾驶扩展最多再投入 3–5 天：用共同的冻结预训练视觉特征，先验证简单预测头在验证集上优于常数基线，再考虑接 LSTM/CfC。旧测试集已反复观察，后续结果应标为探索性；若要独立确认驾驶结论，需要新且未用于选择方案的行程。

| 时间 | 可验收产物 |
|---|---|
| 第 1 周 | 三天 pilot、数据检查、任务与划分决定 |
| 第 2 周 | 稳定基线、变长与 Δt 管线、冻结评价协议 |
| 第 3–4 周 | 两种训练条件、采样对照、等预算调参 |
| 第 5 周 | 时间输入消融、Transformer 参照、成本测量 |
| 第 6 周 | 五种子最终训练、可选驾驶扩展、配置冻结 |
| 第 7 周 | 统一测试评测、置信区间、失败案例和图表 |
| 第 8 周 | 报告、复现检查、演示与时间缓冲 |

四人分工可按数据/采样、模型/训练、评测/统计、报告/复现分配；三人时合并评测与报告，各模块交叉审阅。最后两周优先保证可复现交付。

课程对应：变长 sequence-to-one 任务、前向计算与参数量推导、合理预测、数据划分解释、训练曲线与调参、机制消融及失败案例。Transformer 是题面明确列出的高级概念，但仍需正确实现并解释。伦理讨论应覆盖活动监测隐私、参与者年龄及设备放置的代表性限制，以及跨人群误判的影响。
