## 1. 研究问题与假设

**问题**：在驾驶视频的转向角预测中，LTC 与 CfC 相比于获得同样时间信息的 LSTM，在观测变稀疏时是否具有更好的精度与计算成本取舍？

两个假设分开，**不能互相替代**：

| | 假设 | 说明 |
|---|---|---|
| **主假设 H-A** | 在预先指定的稀疏条件下，CfC（以及 LTC）的 macro MAE 低于 LSTM+Δt | 这是主比较，检验"稀疏时更准" |
| **次假设 H-B** | 从完整历史到稀疏条件，CfC / LTC 的相对退化小于 LSTM+Δt | 鲁棒性补充。**本身预测就差的模型也可能退化很小**，所以 H-B 单独成立不算支持主问题 |

主比较的条件：**随机删除 75% 的历史观测**（当前帧始终保留）。删 50% 和完整历史作为次要条件一并报告。

## 2. 模型与参数配平

所有模型共享同一套冻结的 DINOv2 ViT-B/14 特征（3 s 历史、10 Hz 基础率、30 步），共享同一结构的投影层和读出头，只有时序模块不同。

| 模块 | 可训练参数（实测，输入 64、隐层 64） |
|---|---|
| 共享投影 Linear(1536 → 64) | 98,368 |
| LSTM+Δt：LSTM(65 → 64) | 33,536 |
| CfC（本仓库手写） | 33,024 |
| LTC（ncps 1.0.1，全连接接线） | 33,216（另有 8,192 个冻结掩码，单列不计入） |
| Transformer（最小实验，配置待定） | 待定，按同一口径报告 |
| 共享读出头 Linear(64 → 1) | 65 |

- 三个时序模块相差在 1.5% 以内，是隐层 64 下的自然配平，不额外调整。
- **参数量按模块分列报告**（投影 / 时序 / 读出），不能只报总数，也不能只凭"隐层都是 64"就说配平。
- ncps 自带的 CfC 在同样配置下是 49,536，不用它；用仓库里手写的那个。

## 3. 训练与评测

- **训练**：混合采样增强——每个 batch 抽一种删点率（0 / 50% / 75%），同一 batch 内只用一种（LTC 的 Δt = 0 会产生 NaN）。所有模型用同一份数据、同一增强协议，各自独立训练。
- **评测**：同一 checkpoint 在三种条件下评测，只删历史观测，当前帧保留，Δt 按保留下来的帧重算。
- **窗口规则收紧**：窗口内最大步长 ≤ 0.2 秒（D3 用的是总跨度上限，训练集有 1.54% 的窗口因此混入断档）。
- **目标帧**：与 D2、D3 相同（车速 > 3 m/s、标签不跨 CAN 断档）。
- **补充条件**：原始时间戳断档（自然丢帧）的样本单独评测，只报告，不进主检验。
- **调参预算**：每个模型族沿用 D2/D3 的配方（3 次选学习率 + N 个 seed），N 由第 5 节的试跑确定；上限写进最终版。

## 4. 指标

- **主指标**：macro MAE（按 |转角| 分 < 5°、5–15°、≥ 15° 三档平均，`metrics.macro_mae`）。
- **次指标**：CCC、逐档 MAE、实测计算成本（同设备、同精度、同 batch、预热后同步计时；单窗口延迟与批量吞吐分开报，注明实现方式）。
- 主统计量：两个模型在**同一批目标帧**上的 macro MAE 之差（按帧加权），并按路线簇分解。

## 5. 统计方法与功效（定稿前必须先做试跑）

**不能直接用 D3 的方差估功效**：D3 只有 MLP 和 LSTM 的总体分数，没有配对差值，也没有区分 seed、路线簇、删帧掩码三种波动来源，而且没有经过混合采样训练。

**试跑（开发集，预算有限）**：
1. 在 train 上训练、在 val 上评测 LSTM+Δt 与 CfC 各 3 个 seed（混合采样训练）；
2. **保存逐目标帧的预测**，不只保存汇总指标；
3. 用它估计配对差值在三个层面的方差：seed、路线簇、删帧掩码；
4. 据此确定：最终 seed 数、等价界 δ、以及主检验的形式。

**统计形式（拟定）**：
- 配对差值先在 seed 和掩码上平均，再按路线簇汇总；主检验用 seed × 路线簇的两层重采样。
- 敏感性分析：按会话聚类、按日期聚类。**若结论随聚类方式改变，如实报告敏感性，不取更显著的那个。**
- 等价界 δ 在看到任何测试集结果之前写定，且不得根据试跑结果放宽。功效不足时，报告"未能区分"，不写"实际等价"。
- 多重比较：主检验只有一个（H-A，在 75% 条件下 CfC vs LSTM+Δt）。LTC vs LSTM+Δt、LTC vs CfC、H-B 以及各条件曲线属于次要族，统一做 Holm 校正。

## 6. LTC 的额外要求

沿用[决定记录](decision_2026-09-21_keep_driving.md)的 LTC 表：batch 等于隐层数时的 Δt 错配、Δt = 0 的 NaN、`erev` 初始化固定种子、Δt 是否真的起作用，四条都要先处理。另加：

- **积分子步数敏感性**：同一组权重，在最大间隔条件下分别用 6、12、24 个子步评测，结果明显变化就改用更细的积分重训。这是固定权重下的数值检查，不是三个独立模型的比较。
- 若预算内得不到稳定结果，把 LTC 标为"未完成有效比较"，不能把粗积分的低分写成 LTC 能力不足。
- LTC 与 CfC 的差异不能只归因于"数值积分 vs 闭式近似"，两者不是同一网络的严格等价实现。
