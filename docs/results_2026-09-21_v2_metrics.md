# CfC vs 参数配平 LSTM —— 结果（v2 指标）

test split，rollout 协议，预注册配置（lr=1e-3 k=0.1 aug=full T=16 epochs=30），每个 arm 按 seed 去重，全部在同一平台（5090）上评估。Welch t 检验（t 分布，不是正态近似）。

## 结论

**预注册主指标 macro MAE 上没有差异**（CfC − LSTM = +0.30°，95% CI [-0.23, +0.82]，p = 0.26）。**两个 arm 平均都赢不了在 val 上拟合的常数**（对它的 skill：CfC -0.079，LSTM -0.056）。看过结果后才加入的探索性指标（r、CCC）上 CfC 名义上更高，但绝对值接近 0、依赖少数几个 seed，而且主要反映的是 LSTM 更常输出近似常数，不是 CfC 预测得更好。

## 探索性指标（看过结果后加入，未预注册）

| | CfC 均值 (n) | LSTM 均值 (n) | 中位数 CfC / LSTM | 差 | 95% CI | p | Holm 校正 p |
|---|---|---|---|---|---|---|---|
| CCC | 0.0550 (35) | 0.0199 (35) | 0.0319 / 0.0000 | +0.0351 | [+0.0074, +0.0628] | 0.0137 | 0.0275 |
| Pearson r | 0.0769 (34) | 0.0286 (35) | 0.0718 / 0.0038 | +0.0482 | [+0.0131, +0.0834] | 0.0078 | 0.0235 |

Holm 校正覆盖三个检验（macro MAE、CCC、r）。r 和 CCC 高度相关，基本是同一个问题问了两次。

读这两行时必须同时看下面几点：

- **绝对大小可以忽略。** 各 seed r² 的均值：CfC 1.1%，LSTM 0.6%；最好的单个 seed 也只有 6.0%。两个模型都几乎没有在跟踪转向信号。
- **差异主要来自 LSTM 更常输出近似常数。** |CCC| < 0.005 的 seed：CfC 8/35，LSTM 16/35。
- **在 CfC 内部，r 越高 macro MAE 越差**（Spearman ρ = +0.36，p = 0.034）。输出的变化更多，但没有换来更准。
- **依赖少数几个 seed。** 去掉 CCC 最高的 2 个 CfC seed：CCC p = 0.046，r p = 0.023；去掉 5 个：CCC p = 0.233，r p = 0.089（均未校正）。
- r 那一行 CfC 是 n=34：塌缩成常数的那个 seed 的 r 没有定义。若按 r = 0 计入：差 +0.0460，p = 0.0103。

## 计数

- 赢过 predict-0 的 seed：CfC 14/35，LSTM 22/35（Fisher p = 0.093，不显著）。
- 赢过 val 最优常数的 seed：CfC 6/35，LSTM 6/35（Fisher p = 1.00）。两个 arm 都有约 83% 的 seed 比一个常数还差。
- 严格常数塌缩（输出完全恒定）：CfC 1/35，LSTM 0/35；近似常数（|CCC| < 0.005）：CfC 8/35，LSTM 16/35。严格标志会低估塌缩。
- 种子标准差（macro MAE）：CfC 1.14°，LSTM 1.05°。
- 有 4 个 seed 在多个目录里重复出现，指标逐位相同（4 次相同，0 次不同）；已去重，n 按 seed 计。这些是在不同 git commit 下分别训练的 run，checkpoint 逐字节相同（同一平台 4080 / torch 2.13），说明训练是确定性的。跨平台则不是：同一批 checkpoint 在 4080 与 5090 上评估的 test macro MAE 最多相差 0.105°（97 个 run，中位 0.002°），所以本表全部统一在 5090 上评估。
