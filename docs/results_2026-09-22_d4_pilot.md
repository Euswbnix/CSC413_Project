# D4 试跑：配对差值有多大，波动来自哪里

日期：2026-09-22。目的是给[预注册](preregistration_2026-09-22.md)定等价界和 seed 数，**不是**主比较的结果。只用开发集（train 训练、val 评测），测试集未动。

## 设置

- LSTM+Δt 与手写 CfC，各 3 次选学习率 + 3 个 seed，**混合采样训练**（每个 batch 抽一种删点率 0 / 50% / 75%）。
- 同一个 checkpoint 在三种条件下评测；删帧条件各用 5 组随机掩码。
- 保存了 19 万个目标帧的逐帧预测（66 个模型/seed/条件/掩码组合），方差因此可以分层估计。
- 耗时 61 分钟。

## 验证集分数（macro MAE）

| 条件 | LSTM+Δt（3 个 seed） | CfC（3 个 seed） |
|---|---|---|
| 完整历史 | 15.19 / 15.52 / 16.07 | 17.03 / 17.67 / 18.20 |
| 删 75% | 15.57 / 16.01 / 16.73 | 15.83 / 16.36 / 16.74 |

- 学习率：LSTM 选中 3e-4，CfC 选中 1e-4（网格里最小的一档）。
- **CfC 在完整历史下明显更差，删帧后反而变好**；LSTM 则是删帧后变差 0.38–0.65°。这个方向正是研究问题关心的，但它是开发集上的观察，不作结论。

## 方差分解（CfC − LSTM，macro MAE 度数）

| | 删 75% | 完整历史 |
|---|---|---|
| 平均差值 | +0.210 | +2.034 |
| 跨 seed 标准差 | 0.178 | 0.175 |
| 同一 seed 内跨掩码标准差 | 0.035 | — |
| 跨路线簇的贡献标准差 | 0.069 | 0.219 |
| seed × 路线簇 bootstrap 95% 区间 | [−0.181, +0.620]，半宽 0.401 | [+1.078, +3.107]，半宽 1.015 |

按 seed 数外推半宽（只缩放 seed 那一部分）：n = 5 为 0.310，n = 8 为 0.245，n = 10 为 0.219。

## 由此定下的参数

写进[预注册](preregistration_2026-09-22.md)，不再更改：等价界 δ = 0.5°；每族 8 个 seed；每个条件 5 组掩码；学习率网格加到 {1e-3, 3e-4, 1e-4, 3e-5}；最多 60 个 epoch、早停 patience 8。

## 已知限制

- 验证集只有 7 个路线簇，测试集有 16 个，所以这里的簇间波动估计偏保守（测试集上应更小）。
- CfC 选中了网格最小的学习率，且有一个 seed 跑满 30 个 epoch 才停——原预算把它卡住了，这正是放宽预算的理由。放宽对所有模型族同样适用。
- 试跑的分数用验证集做早停和选学习率，偏乐观；它们只用于估方差，不进结论。
