# 方案：转角预判（2026-10-05 确认，训练开始之前提交）

**定位**：在已完成的 D4（预测当前帧转角）之上加一个扩展任务：**只看到 t 时刻为止的画面，预测 t 之后 0.5 / 1 / 2 秒的方向盘转角**。数据、特征、划分、模型和分析脚本全部沿用 D4。D4 的[预注册](preregistration_2026-09-22.md)和[测试结果](results_2026-09-25_d4_test.md)不因此改动。本文在任何训练之前提交；无论结果对谁有利，都照实报告。

## 1. 问题（事先写定）

- **Q1（主问题）**：历史信息对“预判”是否比对“当前帧”更有用？统计量是历史收益之差：`[MAE_单帧(1 s) − MAE_LSTM(1 s)] − [MAE_单帧(0) − MAE_LSTM(0)]`，完整历史，macro MAE。95% 区间整个大于 0，就判定“是”。
- **Q2**：预判 1 秒时，CfC、LTC、Transformer 各自与 LSTM+Δt 的差值，在完整历史和删 75% 两种条件下，沿用 δ = 0.5° 的三向判定（实际等价 / 有差异 / 未能区分）。
- **Q3**：删帧对预判的伤害是否更大？比较每个模型在 1 秒和 0 秒两个预测时距下，从完整历史到删 75% 的退化量。
- **Q4（只描述）**：各模型的误差随预测时距变化的曲线，以及相对三个免训练基线的改善。

## 2. 任务与标签

- **锚点帧**：与 D4 的目标帧相同（车速 > 3 m/s、标签不跨 CAN 断档、窗口内最大步长 ≤ 0.2 秒），历史窗口仍是 3 秒 30 步。
- **标签**：t + h 时刻的转角，h ∈ {0, 0.5, 1, 2} 秒，由缓存中 10 Hz 的转角序列按相机时间线性插值得到。插值点两侧的帧相隔超过 0.2 秒，或任一侧无效，该标签就作废。**只保留四个时距的标签都有效的锚点**，这样所有时距用的是同一批帧。
- 划分仍是方案 A：训练 65 / 验证 8 / 测试 21 个会话。

## 3. 模型与训练

- **五个模型**：单帧（只看当前帧，33,088 个参数的两层 MLP，无历史）、LSTM+Δt、CfC、LTC（24 个积分子步）、Transformer（真实时间编码）。投影层和 D4 相同；读出头改为 `Linear(64 → 4)`，四个时距各一个输出，所有模型一样。
- **损失**：四个时距标准化后的均方误差取平均（各时距用各自的训练集均值和标准差）。
- **其余沿用 D4**：混合采样（每个 batch 抽一种删帧率），AdamW，学习率 {1e-3, 3e-4, 1e-4, 3e-5} × seed 0，再用选定的学习率跑 seed 0–7，最多 60 个 epoch，patience 8，评测用同样的 5 组掩码。Δt 以秒为单位（[探索实验](explore_2026-09-26_dt_units.md)已表明单位不影响结论）。
- **选择准则**：三个未来时距（0.5 / 1 / 2 秒）× 三种删帧条件的 macro MAE 平均值。
- **免训练基线**：① 最佳常数；② “把当前当未来”，即用模型自己的 0 秒输出充当 t + h 的预测；③ 真实转角的持续预测（用到 CAN，只作难度参照，不是视觉模型）。
- **预算**：5 个模型 × (4 + 8) = 60 次训练。除 LTC 外合计几个小时，LTC 约 20 小时。LTC 纳入与否、是否做测试评测，这两点已于 2026-10-05 确认：LTC 纳入，测试评测做一次。

## 4. 评测纪律

- 开发和选择只用验证集。分析沿用 `d4_analyze.py` 的 seed × 路线簇 bootstrap，另做按会话、按日期聚类的敏感性分析。
- **测试集**：验证结果出来、脚本锁定之后，只做一次测试评测。Q1 是主检验，不校正；Q2 和 Q3 合为次要族，做 Holm 校正。报告中注明：这 21 个测试会话已在“当前帧”任务上评测过（2026-09-25），对新任务不是完全没见过的数据。
- 输出只存放在服务器 `~/workspace/hdd/d4/anticip/`，SwanLab 项目 `CSC413-anticipation`。

## 5. 可选的延伸（主体完成后再定）

**驾驶行为预判**：HDD 压缩包里有每个会话的 EAF 标注和 TRN 预先整理的 12 类行为标签（第一周检查已记录，尚未解压）。可以做“未来 τ 秒内是否开始某个动作”的预判，更接近“交互预判”的设想。前提是先把标签解压出来，并只用统计量核对它与相机时钟的对齐；核对不过就不做。
