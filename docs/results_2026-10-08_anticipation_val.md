# 转角预判的验证集结果：历史对预判的帮助比对当前帧小

日期：2026-10-08。方案见 [`plan_2026-10-05_steering_anticipation.md`](plan_2026-10-05_steering_anticipation.md)（提交 `c0e0c10`，训练之前写定），代码在 `e94d3e5`。**本文只有验证集结果**；学习率也是在这 8 个验证会话上选的，所以这些数字偏乐观。测试集没有参与，方案第 4 节规定的唯一一次测试评测尚未执行。

**结论（验证集）：主问题 Q1 的答案是“否”。** 历史带来的收益（单帧模型与 LSTM+Δt 的 macro MAE 之差）在预测当前帧时是 4.36°，预判 1 秒时只有 1.10°，两者之差 −3.26°，95% 区间 [−4.80, −1.88] 整个小于 0。按会话、按日期聚类结论相同。也就是说，过去 3 秒的画面主要帮助模型估计“现在”的转角，对“将来”的转角帮助有限，到 2 秒时几乎没有（+0.26°）。

## Q1（主问题）：历史对预判是否更有用

历史收益 = 单帧的 macro MAE − LSTM+Δt 的 macro MAE，完整历史：

| 时距 | 0 秒 | 0.5 秒 | 1 秒 | 2 秒 |
|---|---|---|---|---|
| 历史收益（度） | +4.355 | +2.413 | +1.097 | +0.259 |

- **统计量**（1 秒的收益减 0 秒的收益）：−3.258，95% 区间 [−4.799, −1.875]。按方案的规则，区间整个大于 0 才判“是”；这里整个小于 0，判定为“否，反而更小”。
- **敏感性**：按会话聚类 [−4.898, −1.871]，按日期聚类 [−6.011, −0.984]，结论相同。
- **一个事先没有写进方案的核对**：各时距的标签分布不同（最佳常数的 macro MAE 从 30.6° 降到 26.1°），跨时距直接相减可能受此影响。改用相对最佳常数的技能分（1 − MAE / 常数基线）重算，历史收益依次为 0.142 / 0.082 / 0.039 / 0.010，方向和结论不变。

- **Q2**：预判 1 秒时，CfC 与 LSTM+Δt 未能区分，也没有达到“实际等价”（区间超出 ±0.5°）；完整历史下按日期聚类的区间是 [+0.110, +1.687]，不含 0，与另外两种聚类方式不一致。LTC 比 LSTM+Δt 差约 2.6–2.8°，Transformer 好约 1.5°，两种条件下都如此。模型之间的排序与 D4（预测当前帧）一致。
- **Q3**：删帧对预判的伤害并不比对当前帧更大。LSTM+Δt 和 Transformer 在 1 秒时的退化反而略小（约 −0.2°）。CfC 的 +1.33° 来自另一个现象：它在 0 秒时删帧后误差反而下降 1.65°（19.79 → 18.15），1 秒时只下降 0.32°；这与 D4 里 CfC 的 H-B 为负是同一类现象，不能读成“预判更怕删帧”。

## 与 D4 的关系（只描述）

本实验的 0 秒输出与 D4 的专用模型不是同一回事：这里一个模型同时输出四个时距，选择准则只看三个未来时距。完整历史下的 0 秒验证 macro MAE，本实验为 LSTM+Δt 17.78、Transformer 16.12，D4 的专用模型为 15.44、14.76，差约 1.4–2.3°。Q1 的两端用的都是本实验内的模型，不受此影响。
