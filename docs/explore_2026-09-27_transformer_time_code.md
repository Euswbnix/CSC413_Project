# 探索实验方案：Transformer 的时间编码消融（2026-09-27，运行之前写定）

**性质**：测试评测之后才加的**探索性**实验。[预注册](preregistration_2026-09-22.md)第 9.1 节写明，Transformer 最小实验“不追加架构搜索或时间编码消融”。本实验是在那之后另立的，不修改第 9.1 节，也不改变 [D4 测试结果](results_2026-09-25_d4_test.md)。**只用验证集，不读取测试集。** 本文在任何训练开始之前提交；无论结果如何，都照实报告。

## 问题

补充实验里，参数量相近的最小 Transformer 在验证集和测试集上都比 LSTM+Δt 低约 1°。它读取的是每个保留帧相对目标帧的**真实时间**（删帧后保留原时间戳）。**问题：这个优势有多少来自真实时间戳？删帧后如果只知道先后顺序，或者完全没有显式的时间信息，Transformer 还剩多少？** 这与本项目的研究问题直接相关：稀疏观测下，模型能不能用上真实的时间间隔。

## 设计（除时间编码外，一切沿用第 9.1 节）

三个变体用同一个最小 Transformer：一层 pre-norm 编码层，64 维、4 头，前馈宽度 128，GELU，无 dropout；因果掩码和 padding 掩码；只读最后一个有效 token。时间编码都没有可训练参数，所以三者的参数量完全相同（时序模块 33,472）。

| 变体 | 加到投影特征上的编码 | 状态 |
|---|---|---|
| **real**（对照） | 第 9.1 节原样：`p_i = (t_i − t_target) / 0.1 s` 的正弦编码 | 已训练（D4 补充实验），直接复用 |
| **index** | 同一正弦公式，但 `p_i = i − i_last`，即删帧后压紧的序号（目标帧为 0，前一个保留帧为 −1，依此类推），不含真实间隔 | 新训练 |
| **none** | 不加任何编码；只有因果掩码带来的先后顺序 | 新训练 |

- 完整历史下，相邻步长约 0.1 s，所以 real 和 index 几乎相同；两者的区别只在删帧之后出现。这正是要检验的地方。
- **预算与协议**：与第 9.1 节相同。每个变体 4 个学习率 {1e-3, 3e-4, 1e-4, 3e-5} × seed 0，再用选定的学习率跑 seed 0–7。最多 60 个 epoch，早停 patience 8。混合采样，选择准则为三种条件的平均 macro MAE，评测用同样的 5 组掩码。
- **输出位置**：服务器 `~/workspace/hdd/d4/dinov2_tcode_index/`、`d4/dinov2_tcode_none/`；SwanLab 项目 `CSC413-D4-explore`。

## 分析（只用验证集，名义 95% 区间，seed × 路线簇 bootstrap）

1. index − real、none − real，三种条件各算一次，另算 H-B（从完整历史到删 75% 的退化之差）。
2. 各变体与 LSTM+Δt 的差值，作为参照。

## 事先写定的解读规则

- **删 75% 条件下 index − real 大于 +0.5°**（等价界），就判定“真实时间戳对这个 Transformer 在稀疏条件下有实质帮助”。如果 95% 区间整个落在 ±0.5° 内，就判定“在这个设置下，真实时间戳相对压紧序号没有实质作用”。其余情况判为“未能区分”。
- none − real 按同样的规则判读，回答“有没有显式的时间或顺序编码”这个问题。
- 完整历史下 index 与 real 应当接近。如果差距超过 0.5°，说明编码尺度本身有影响，照实报告，并提醒上一条结论受此干扰。
- 这是探索结果。验证集同时用于选择学习率，所以数字偏乐观，三个变体一样。结果不进入任何检验族，不改写第 5 节和第 9 节的结论。本方案不包括任何测试集评测。
